# 用語集

ユーザー向け日本語の表記ゆれを防ぐための正本(Issue #179)。
コード・コメント・README・docs・スクリプトの文言はこの表に従う。

## 考え方

- 「起動/停止」は**出来事**の言葉(何が起きたか)に使う。
- 「オン/オフ」は**状態**の言葉(今どうなっているか)に使う。

## 統一表

| 概念 | 統一 | 例 |
|---|---|---|
| PCの状態 | **オン / オフ**(「オンライン/オフライン」は使わない) | `PC: オン` |
| PCを立ち上げる操作 | **PCの起動** | Botコマンド説明: `PCの起動` |
| PCの起動指示の結果 | **PCの起動を指示しました**(WOLは内部の手段のため文言に使わない) | `PCの起動を指示しました。` |
| PCの起動指示の失敗 | **PCの起動の指示に失敗しました** | `PCの起動の指示に失敗しました。` |
| PCが立ち上がった結果の通知 | **PCが起動しました** | 状態変化の通知 |
| PCが停止した結果の通知 | **PCが停止しました** | 状態変化の通知 |
| M5Stack自身の立ち上がり | **M5Stackが起動しました**(助詞を補う) | 起動通知 |
| 再起動 | 対象を必ず明記: **PCの再起動** / **M5Stackを再起動します** | `PCの再起動を受け付けました。` |
| シャットダウン | **PCのシャットダウン**(操作名。結果は「停止しました」) | `PCをシャットダウンしますか？` |
| PCがオンで操作可能 | **再起動・シャットダウンができます** | `/status` |
| PCがオフで操作可能 | **起動できます** | `/status` |
| PCがオンで操作サービス応答なし | **⚠️ 再起動・シャットダウンはできません** | 次行に `PC側の操作サービスが応答していません` |
| 操作ロック中 | **🔒 操作をロック中** | 次行に `解除するまで起動・再起動・シャットダウンはできません`。PC・操作サービスの状態より優先 |
| `/status` の見出し | **🖥️ PC ・ {オン/オフ}** / **📱 M5Stack** | どちらも太字。2つのブロックの間に空行を1つ置く |
| バッテリーの状態 | **🔋 残量% 給電状態** | `🔋 100% 満充電・給電中` / `🔋 78% 電池駆動` / `🔋 95% 充電中`。未取得は `🔋 不明` |
| 端末のバージョン | **🏷️ v{version}** | `🏷️ v0.13.0` |
| `/status` のボタン | **🔄 PCを再起動** / **⏻ シャットダウン** / **⏻ PCを起動** / **🔓 ロックを解除** / **↻ 最新の状態に更新** | 押しても確認を挟む。1タップで電源は動かない |

## 補足

- M5Stack本体の画面はASCIIフォントで日本語を描画できないため、画面表示は
  英語のまま(`ONLINE` / `OFFLINE`、`REBOOT` / `SHUTDOWN` 等)。画面側は対象外だが、
  日本語の「オン/オフ」と1対1に対応する。
- 変えるのは人間が読む日本語の表示文言だけ。コマンド名(`/status` `/wake` 等)、
  `callback_data`、NVSキー、設定キー、シリアルログの英語メッセージは変えない。
- 文言を組み立てる関数はできるだけ1箇所に寄せる。
  日本語の状態表示と通知文は `firmware/src/net.rs` の `pc_online_label_ja` /
  `pc_state_notification_ja` が正本。起動指示の応答・待機の通知文は
  `shared/wake-check` の `wake_request_text` / `wake_request_failed_text` /
  `wake_succeeded_text` / `wake_timed_out_text` が正本。電源操作の結果文は
   `firmware/src/bridge_client.rs` の `accepted_text` / `rejected_text` /
   `failed_text` が正本。firmware更新の確認・適用文は
   `shared/pc-remote-signing` の `ota_confirm_text` / `ota_applying_text` / `firmware_available_text` が正本。
   `/status` の全文とボタンは同crateの `status_message_html` / `status_buttons` が正本
   (`/status` の応答だけ `parse_mode=HTML` で送る。他の送信経路へは付けない)。
   給電変化の通知文は `shared/battery` の `power_state_notification_ja` が正本。
- 設定名の「WOLポート」は変えない。設定キー(`wol_port`)・設定メニューのラベルで、
  技術的な設定項目のため。ユーザー向けの操作・結果の文言だけを「PCの起動」に揃える。
