# Cost Policy

このプロジェクトの外部操作経路は **コストゼロ** を絶対条件にします。

## 禁止

- 月額課金サービスを運用必須経路にすること。
- 従量課金サービスを運用必須経路にすること。
- 無料枠超過で課金される可能性があるサービスを運用必須経路にすること。
- 有料VPS、常時稼働クラウド、課金型キュー、課金型DBを追加すること。

## 許可

- Telegram Bot APIの通常利用。支払い方法登録や有料オプションを使わないこと。
- 無料・オープンソースのクライアントソフトウェア。
- 既に所有している自宅ルーターのVPN機能。ただし今回の環境では前提にしない。

## 要レビュー

- Cloudflare Workers、Durable Objects、Tailscaleなど、2026-09-01時点で無料プランがある外部サービス。

これらは無料プラン条件や利用上限に依存するため、初期の運用必須経路にはしません。実験的に使う場合でも、課金が発生しないこと、無料枠超過時に失敗すること、支払い方法登録が不要または課金停止できることを事前確認します。
